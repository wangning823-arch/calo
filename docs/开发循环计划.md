# Calo 开发循环计划

> 版本：v1.0
> 日期：2026-09-08
> 说明：M0~M3 完整开发循环，每个阶段包含开发提示词 + 测试验证提示词

---

## 总体策略

1. **严格按依赖顺序执行**：T1 → T2 → T3 → T4
2. **每个子任务完成后运行测试**，通过后才进入下一个
3. **每个阶段结束做集成测试**，确保模块间衔接正常
4. **遇到阻塞时暂停**，记录问题并跳到下一个可并行的任务

## 循环执行规则

1. **顺序执行**：T1 → T2 → T3 → T4，不可跳过
2. **测试先行**：每个任务完成后运行测试，通过后才进入下一个
3. **阻塞处理**：遇到阻塞记录问题，跳到下一个可并行的任务
4. **集成测试**：每个阶段结束后运行集成测试
5. **代码质量**：每次提交前运行 Laravel Pint
6. **文档更新**：每个阶段完成后更新需求文档状态

---

## 执行命令

开始循环：

```bash
# 启动开发循环
/loop 30m 检查当前任务状态，如果任务未完成则继续开发，如果任务完成则标记完成并进入下一个任务。参考 docs/开发循环计划.md 执行。
```

手动触发单个任务：

```bash
# 执行指定任务
请执行任务 T1.1：数据库基础改造
```

查看任务进度：

```bash
# 查看所有任务状态
请列出所有任务的当前状态
```
